# Text Colorizer 文字着色（SillyTavern 扩展）

一个 SillyTavern（酒馆）第三方 UI 扩展：为聊天消息中的四类文本分别配置 **纯色** 或 **静态循环渐变** 颜色，控制面板分「纯色 / 渐变」两栏，面板字号与配色跟随酒馆当前主题。

## 功能

### 可着色的文本类别

| 类别 | 对应酒馆渲染结果 | 说明 |
| --- | --- | --- |
| 主要文本 | 普通叙述与旁白 | 消息正文默认颜色 |
| 斜体文本 | `*文本*` / `_文本_` → `<em>` `<i>` | 心理活动、补充说明 |
| 下划线文本 | `++文本++` → `<u>` `<ins>` | 强调内容 |
| 引用 / 对话 | `> 引用` → `<blockquote>`；`"…"`、`“…”`、`「…」` 等 → `<q>` | 引用块与双引号对话 |

### 配色模式

- **纯色**：整段文本使用同一个自定义颜色。
- **静态循环渐变（主体）**：逐字符沿色标插值着色，**每 N 个字（默认 30 字）走完一遍色标循环**，循环到第 N+1 字自动回到起点；**纯静态、不动画**。
- 每条规则可独立选择：`跟随全局` / `使用纯色` / `使用渐变`；全局默认「渐变优先」，保证渐变在画面中占主体，纯色仅作为备选模式。
- 渐变支持 2–5 个色标，可随时添加 / 删除；面板内实时预览。

### 面板

- 纯色面板、渐变面板 **左右两栏分开**；窄屏（手机端）自动切换为单列。
- 面板不写死字号，自动跟随酒馆字号；背景、边框、正文色、强调色全部引用酒馆主题变量，切换主题时自动适配。
- 顶部可调整：启用开关、全局模式、渐变循环字数、是否同时着色用户消息、是否跳过代码块。

## 安装方式（手机 / 电脑酒馆通用）

1. 打开酒馆 → 右上角 **扩展（Extensions）** 面板。
2. 进入 **Install Extension（安装扩展）**。
3. 粘贴本仓库地址：

   ```
   https://github.com/yg0108011/st-text-colorizer
   ```

4. 安装完成后在扩展列表中启用 **Text Colorizer 文字着色**，颜色配置位于扩展设置面板内。

> 若指定分支，默认使用仓库主分支 `main`。

## 使用说明

1. 在扩展设置中打开「启用文字着色」。
2. 全局模式选择「渐变优先」（默认，推荐）或「纯色优先」。
3. 在 **渐变面板（主体）** 为四类文本挑选色标；在 **纯色面板** 可单独把某一类改成纯色。
4. 「渐变循环字数」即一个渐变循环覆盖的字数，默认 `30`。
5. 修改即时生效，自动保存；点击「重新着色当前聊天」可手动刷新整屏消息。

## 默认配色（参考示例图）

- 主要文本：粉紫 → 淡蓝渐变
- 斜体：淡蓝 → 更浅的蓝
- 下划线：暖黄 → 粉橘
- 引用 / 对话：粉紫 → 淡蓝渐变（与主文本一致）

## 工作原理

- 监听 `CHARACTER_MESSAGE_RENDERED` / `USER_MESSAGE_RENDERED` / `MESSAGE_EDITED` / `MESSAGE_SWIPED` / `STREAM_TOKEN_RECEIVED` / `CHAT_CHANGED` / `GENERATION_ENDED` 等事件，消息渲染完成后对 `.mes_text` 内的文本节点着色。
- 着色前先移除本扩展注入的 `<span class="stcx">`，保证重复渲染幂等、不嵌套叠加。
- 代码块、行内代码、消息元信息（昵称、时间戳、头像、工具调用等）默认跳过，不参与着色。

## 兼容性

- 适用 SillyTavern release 版 1.10 及以上；纯前端 UI 扩展，不依赖服务器插件或 Extras API。
- 手机端酒馆、桌面端酒馆行为一致。
